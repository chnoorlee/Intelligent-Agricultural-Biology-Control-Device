# Titan Bumblebee Y3 VTOL Fixed Wing RC Airplane FPV

**参考来源:** https://makerworld.com/zh/models/1032743-titan-bumblebee-y3-vtol-fixed-wing-rc-airplane-fpv

## 说明

Titan Bumblebee Y3 是一款可垂直起降（VTOL）的固定翼 FPV 遥控飞机开源设计方案。

本项目在大农场版无人机系统中参考了该设计的飞控架构与 VTOL 机架布局方案。

## 获取方式

该模型托管于 Makerworld 平台，需通过浏览器访问以下链接下载 STL 模型文件及相关文档：

1. 访问 https://makerworld.com/zh/models/1032743-titan-bumblebee-y3-vtol-fixed-wing-rc-airplane-fpv
2. 点击「下载模型」获取 3D 打印文件（STL 格式）
3. 组装说明与飞控配置指南请参阅模型页面描述
