# 硬件方案总览 — 智能农业生物防控装置 (家庭版)

## 版本信息
- 方案版本: v1.0
- 适用场景: 家庭阳台 / 庭院种植 (7-30㎡)
- 设计理念: 低成本、易部署、低功耗、免维护
- 硬件总成本: ¥150-180 (不含树莓派) / ¥590-620 (含树莓派整套)

## 通信架构

```
树莓派 (计算端)           STM32 (控制端)
┌──────────────┐         ┌───────────────┐
│  YOLO检测    │         │  传感器轮询    │
│  ↓           │  UART   │  ↓             │
│  决策引擎    │←────────→│  执行器控制    │
│  (阈值判断)  │115200bps│  (PWM+GPIO)   │
└──────────────┘         └───────────────┘
```

通信协议: 自定义ASCII协议, 以换行符`\n`分隔帧, 格式: `CMD:PARAM\n`

| 指令方向       | 格式                   | 含义                      |
|---------------|-----------------------|---------------------------|
| 树莓派 → STM32 | `DETECT:sparrow,0.92\d` | 检测到麻雀, 置信度0.92      |
| 树莓派 → STM32 | `DRIVE:1\n`            | 激活驱离 (蜂鸣+闪灯)        |
| 树莓派 → STM32 | `DRIVE:0\n`            | 停止驱离                    |
| 树莓派 → STM32 | `MODE:day\n`           | 切换到白天模式              |
| 树莓派 → STM32 | `MODE:night\n`         | 切换到夜间模式              |
| STM32 → 树莓派 | `SENSOR:T:28.5,H:65.2,L:1023,D:156\n` | 传感器数据(T温度,H湿度,L光照,D距离) |
| STM32 → 树莓派 | `STATUS:OK\n`          | 状态正常                    |
| STM32 → 树莓派 | `STATUS:ERR_BUZZ\n`    | 蜂鸣器故障                  |

## 工作流程

```
1. 摄像头实时采集图像 (30fps)
    ↓
2. 树莓派运行YOLO轻量化模型检测
    ↓
3. 检测到害鸟 → 置信度 > 阈值(0.6)
    ↓
4. 树莓派通过UART发送 DETECT 和 DRIVE:1 指令
    ↓
5. STM32 收到指令:
   ├─ DHT22 检测当前温湿度 (记录到日志)
   ├─ GL5528 检测环境光 (决定爆闪灯亮度模式)
   ├─ HC-SR04 测距 (确认鸟类在有效范围内)
   ├─ 蜂鸣器输出多频率Arpeggio驱鸟声波 (2kHz→4kHz→8kHz循环)
   └─ 爆闪灯以1Hz频率闪烁 (夜间降低占空比)
    ↓
6. 持续驱离 5 秒后停止
    ↓
7. 如果 30 秒内再次检测到害鸟 → 加大驱离力度/延长时间
    ↓
8. 超时(>5分钟)停止驱离 → 进入待机节能模式
```

## 供电方案

```
输入: 12V DC 电源适配器 (3A) 或 12V 太阳能电池板+控制器 (可选)
  │
  ├─ 12V BUS ─→ LED灯带 (直接)
  │          ─→ 蜂鸣器 (经三极管)
  │
  ├─ MP1584 #1 → 5V/3A → 树莓派4B
  │                    → HC-SR04 ×2
  │                    → 继电器模块
  │
  └─ MP1584 #2 → 5V/3A → Mini MP1584 → 3.3V → STM32
                                           → DHT22
                                           → GL5528
                                           → PC817光耦
```

额定总功耗: ~15W (白天, 驱离时峰值) / ~5W (待机)

## 外壳与安装

- 防水外壳: ABS 200×120×75mm, IP65
- 安装方式: 万向支架 + U型抱箍, 可固定在阳台栏杆或墙壁
- 出线密封: PG9 电缆防水接头 ×4
- 摄像头角度: 向下倾斜 15°~30°, 覆盖阳台全域
- 建议安装高度: 距地面 1.5m ~ 2.5m
