## 蜂鸣器驱动电路

```
STM32 PA0 (TIM2_CH1 PWM)
        │
        ├── R1 (1KΩ) ──┬── Q1 (2N2222) Base
        │              │
        │        Q1 Emitter ── GND
        │        Q1 Collector ── BUZZER ── +12V
        │                       │
        │              D1 (1N4007) [续流保护]
        │                       │
        └── GND ────────────────┘

工作原理: PA0输出PWM方波 → 三极管开关放大 → 驱动蜂鸣器发声
频率范围: 200-8000Hz (Arpeggio模式用于多种鸟类驱离)
```

## 爆闪灯驱动电路

```
STM32 PA1
        │
        ├── R2 (220Ω) ──┬── U1 (PC817) LED [光耦输入]
        │               │
        │         U1 光电三极管 Collector ── VCC_5V
        │         U1 光电三极管 Emitter ── R3 (1KΩ) ── Q2 (2N2222) Base
        │                                         │
        │                                   Q2 Emitter ── GND
        │                                   Q2 Collector ── RELAY Coil ── VCC_5V
        │                                                    │
        │                                              D2 (1N4007) [续流]
        │                                                    │
        └── GND ─────────────────────────────────────────────┘

RELAY NO ── 12V LED灯带 ── GND_12V
RELAY COM ── +12V

工作原理: PA1高电平 → 光耦导通 → 三极管导通 → 继电器吸合 → LED亮
         PA1低电平 → 全部断开 → LED灭
光耦隔离防止继电器反电动势干扰MCU
```

## 超声波测距电路

```
STM32 PB0 (Trig)
        │
        └── HC-SR04 Trig引脚

STM32 PB1 (Echo)
        │
        └── HC-SR04 Echo引脚 (5V电平, 经电阻分压接PB1)

HC-SR04 VCC ── +5V
HC-SR04 GND ── GND

注意: HC-SR04 Echo输出为5V电平，STM32 GPIO为3.3V容忍5V，
      可直接连接，但为安全建议串接1KΩ电阻。
```

## 光照传感器电路

```
+3.3V ──┬── LDR (光敏电阻 GL5528)
        │
        ├── ADC_IN ── STM32 PA4
        │
        └── R (10KΩ) ── GND

分压原理: Vout = 3.3V * R / (R + LDR)
光照强 → LDR↓ → Vout↑ → ADC值↑
光照弱 → LDR↑ → Vout↓ → ADC值↓
```

## DHT22温湿度电路

```
+3.3V ──┬── R_Pullup (4.7KΩ)
        │
        ├── STM32 PC0 (Open-Drain)
        │
        ├── DHT22 DATA
        │
DHT22 VCC ── +3.3V
DHT22 GND ── GND

单总线协议: 主机拉低发起通信, 从机拉低回应, 40bit数据
```

## 供电电路

```
12V DC ──┬── DC-DC MP1584(1) ── 5V ──┬── 树莓派4B (3A max)
         │                            ├── 继电器模块
         │                            ├── HC-SR04
         │                            └── DC-DC MP1584(2) ── 3.3V ── STM32 + 传感器
         │
         └── 12V LED灯带 (直接供电)

电源保护:
- 输入: SS34 肖特基二极管 (防反接)
- 输出: 100uF/25V 电解 + 100nF 陶瓷 (去耦)
- TVS SMBJ15CA (瞬态电压抑制,防雷击浪涌)
```

## 通信接口

```
树莓派 GPIO14 (TXD) ── STM32 PA10 (RXD)
树莓派 GPIO15 (RXD) ── STM32 PA9 (TXD)
树莓派 GND ──────────── STM32 GND

电平匹配: 均为3.3V, 无需电平转换
波特率: 115200, 8N1
```

## PCB布局建议

1. **电源部分**: 大电容靠近电源输入端，DC-DC模块远离敏感模拟电路
2. **数字/模拟隔离**: 数字地(GND_D)与模拟地(GND_A)通过0Ω电阻单点连接
3. **蜂鸣器**: 远离ADC采样电路，PWM信号走线避开模拟输入
4. **超声波**: Trig/Echo信号尽量短, 避免与其他高速信号平行
5. **光耦**: 高低压区域保持>4mm爬电距离
6. **散热**: 12V → 5V DC-DC转换效率约85%, 2A时约有1.8W耗散功率
