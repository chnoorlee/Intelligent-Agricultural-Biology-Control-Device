# 详细接线指南 — 智能农业生物防控装置 (家庭版)

## 安全须知

> ⚠️ **操作前必读**
> 1. 所有接线操作必须在**断电**状态下进行
> 2. 上电前用万用表检查电源与地之间是否存在短路
> 3. 12V 电源接入前请确认降压模块输出电压已调至目标值 (5V / 3.3V)
> 4. HC-SR04 Echo 引脚输出 5V 电平，务必加 1KΩ 串联电阻接入 STM32 GPIO
> 5. 继电器强电侧 (12V LED 灯带) 必须使用光耦隔离
> 6. 户外使用请将所有裸露焊点用热缩管 + 704硅橡胶双重密封

## 2. STM32 ↔ 树莓派 UART 通信接线

```
       树莓派 40Pin GPIO                          STM32F103C8T6
   ┌──────────────────────┐                 ┌──────────────────┐
   │ 3.3V  (Pin 1)        │                 │ 3.3V             │
   │ 5V    (Pin 2/4)      │                 │ 5V (USB/Vin)     │
   │ GPIO14 (Pin 8) ─TXD──┼─────────────────┼─ PA10 (USART1_RX)│
   │ GPIO15 (Pin 10)─RXD──┼─────────────────┼─ PA9  (USART1_TX)│
   │ GND   (Pin 6) ───────┼─────────────────┼─ GND             │
   └──────────────────────┘                 └──────────────────┘

接线要点:
  - 均为 3.3V 电平，无需电平转换
  - TXD→RXD, RXD→TXD (交叉连接)
  - GND 必须连通 (共地)
  - 波特率: 115200, 8N1
  - 通信协议以 `\n` 作为帧结束符

树莓派端启用 UART:
  $ sudo raspi-config → Interface Options → Serial Port
  → "Would you like a login shell over serial?" → No
  → "Would you like the serial port hardware to be enabled?" → Yes
  设备路径: /dev/serial0 或 /dev/ttyAMA0
```

  - 测距周期 > 60ms，避免前一回声被误判
  - 精度: ±3mm, 盲区: 2cm, 最大量程: 400cm

## 9. 常见问题排查

| 现象                        | 可能原因                        | 排查步骤                                      |
|-----------------------------|---------------------------------|-----------------------------------------------|
| STM32不工作, 无任何输出     | 供电异常/固件未烧录              | ① 测3.3V供电 ② 检查BOOT0=0 ③ 重新烧录固件     |
| 蜂鸣器不响                  | PWM未输出/三极管焊反             | ① 测PA0有无方波 ② 检查三极管B,C,E焊接         |
| LED不闪                     | 继电器不吸合/光耦失效             | ① 测PA1有无高低变化 ② 测光耦④脚电压            |
