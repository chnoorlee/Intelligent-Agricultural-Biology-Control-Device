# 智能农业生物防控装置
## Intelligent Agricultural Biology Control Device

基于计算机视觉与嵌入式技术的生态友好型智能驱鸟系统，覆盖家用阳台、小型农场、大型规模化农场三类场景，实现精准鸟类识别、无伤害驱离与自动化运维，助力农业生产降本增效与绿色转型。

---

## 📌 项目背景
传统鸟类防护手段普遍存在防护效果差、易造成环境污染与动物伤害、缺乏智能化监测能力、人力运营成本高昂等痛点。本项目针对不同规模的种植场景，打造分层级的智能生物防控方案，以AI识别为核心，结合多元物理驱离技术，在保护生态与生物多样性的前提下，有效降低鸟类带来的经济损失。

## ✨ 核心特性
- **精准智能识别**：基于微调YOLO图像分割模型实现害鸟实时分类识别，可区分益鸟与害鸟，大幅降低误判风险
- **生态友好防控**：采用声光模拟、超声波干扰等无伤害驱离技术，全程无毒无污染，保护农田生态平衡
- **全场景覆盖**：提供家用阳台版、小型农场版、大型农场版三类标准化方案，适配从家庭种植到规模化农场的多元需求
- **低运维自动化**：全系统集成控制，支持太阳能供电、无人机自动返航充电，显著减少人力投入与运营成本
- **数据驱动优化**：支持鸟群活动规律统计分析，可定制化调整驱离策略与无人机巡航路线

## 🛠️ 分场景技术方案
### 🏠 家用阳台版
面向家庭阳台、庭院种植场景，主打低成本、易部署、低功耗。
- 技术架构：顶部摄像头实时采图 → 轻量化YOLO模型后端识别 → STM32开发板接收指令 → 声光驱离装置执行
- 驱离方式：模拟鸟类天敌叫声的蜂鸣器 + 绿色频闪爆闪灯
- 覆盖范围：7-30 平方米
- 硬件成本：150-180 元

### 🌾 小型农场版
面向1-6亩小型农场、果园场景，主打主动式驱赶与太阳能长效续航。
- 技术架构：OpenMV云台360°图像追踪 → ESP32主控调度 → Mini无人机定点抵达驱赶
- 能源系统：太阳能追光充电模块 + 后备充电电池双供电方案
- 驱离方式：无人机机载超声波模块
- 工作流程：云台识别鸟情 → 无人机前往定位 → 超声驱赶 → 驱赶成功自动返航充电 → 驱赶失败后台向用户告警

### 🌳 大型农场版
面向20-30亩以上规模化农场，主打长续航巡航与AI路径规划。
- 技术架构：固定翼无人机嵌入式飞控 → 图像传输视觉模块回传画面 → 后端YOLO模型集群分析
- 双模式控制：
  - **自动巡航模式**：预设巡航路线，机载超声模块常态化驱鸟，适用于低密度鸟群
  - **人工介入模式**：高密度鸟群切换人工操控，结合Deepseek API统计鸟群活动规律，迭代优化驱鸟路线
- 核心硬件：嵌入式飞控系统、GPS定位模块、舵机飞控调平、远距离图像回传模块

## 📊 测试与试点效果
### 实验室基准测试
| 产品版本   | 鸟类识别精度 | 驱避成功率 | 系统响应时间 |
|------------|--------------|------------|--------------|
| 家用版     | 90.7%        | 85.8%      | 86.8ms       |
| 小型农场版 | 85.8%        | 93.7%      | 1.25s        |
| 大型农场版 | 81.5%        | 96.8%      | 3.39s        |

### 实地试点验证
- **宁波半岛华府（家用试点）**：14天连续测试，驱避成功率90.6%，减少鸟类损害约31%
- **温州肯恩农场（小型农场试点）**：14天连续测试，驱避成功率94.2%，减少鸟类啄食约32%
- **宁波海曙区水家村（大型农场试点）**：15天连续测试，驱避成功率96.5%，减少鸟类损害约45%

## 🧰 技术栈
- **算法层**：Python、YOLO 图像分割与目标检测
- **嵌入式层**：STM32、ESP32 固件开发
- **无人机系统**：嵌入式飞控开发、固定翼/多旋翼硬件集成
- **数据与服务**：Deepseek API 行为分析、轻量云服务部署
- **硬件集成**：摄像头模组、超声波模块、声光报警模块、太阳能供电系统

## 🚀 快速开始
### 家用版部署
1. 硬件准备：国产摄像头模组、STM32开发板、蜂鸣器、爆闪灯模块
2. 环境部署：配置Python推理环境，下载预训练YOLO模型权重
3. 固件烧录：编译并烧录STM32主控固件，完成硬件接线
4. 启动运行：执行检测程序，根据场景调整识别阈值与驱离参数

各版本详细部署与调试说明，请对应目录下的 `README.md` 文档。
